# Ma’ak — Pixel invitation

لعبة ويب تفاعلية بـ HTML وCSS وJavaScript، جاهزة للنشر على Vercel. لا تحتاج Python أو npm أو سيرفر خلفي.

## الرحلة

اضغطي الكلية الزهرية، أجيبي السؤال عند المدخل، ثم تحركي إلى الباب. داخل الكلية امشي إلى الكرسي المشمشي واضغطي «اجلسي». تصل المتطوعة وتجلس، وتضيء اللمبة مع بداية الحديث. النهاية GROUP 11 وBOOTH 5.

التحكم: الأسهم أو WASD، وE للتفاعل. يمكن الضغط على الأرض للمشي. تظهر أزرار لمس على الجوال.

## Vercel

ارفعي محتويات هذا المجلد مباشرة في جذر مستودع `maak-invetation`؛ يكون `index.html` بجانب `game.js` و`style.css` و`vercel.json` ومجلد `assets`.

إذا كانت ملفات Python السابقة في المستودع، أزيليها من نسخة الموقع، ومنها `requirements.txt` وملفات `.py`. في إعدادات Vercel اختاري Framework Preset: **Other**، واجعلي Root Directory هو المجلد الذي يحتوي `index.html`. لا يلزم Install Command أو Build Command. Output Directory هو `.`.

## تشغيل محلي

يمكن فتح `index.html` مباشرة في المتصفح. أو استخدمي Live Server داخل VS Code. ويمكن تشغيل خادم بسيط إن كان Python مثبتاً:

```bash
python -m http.server 8000
```

ثم افتحي http://localhost:8000.

## التعديل

- `game.js`: السؤال وتسلسل المشاهد، أماكن المشي والشخصيات، توقيت المتطوعة واللمبة.
- `index.html`: النصوص والنهاية GROUP 11 وBOOTH 5.
- `style.css`: تنسيق الواجهات والألوان.
- `assets/`: الصور والشعار والشخصيات والخط العربي.

الصوت اختياري ويبدأ بزر «الصوت». كل الصوت مولّد محلياً في المتصفح. لا تُرسل اللعبة أي بيانات ولا تطلب تسجيل دخول.

## دعوة باسم كل بنت

أضيفي `?name=دانا` لنهاية نفس رابط الموقع، مثال:

`https://maak-invitation.vercel.app/?name=دانا`

في النهاية تظهر «دانا، ننتظرك في بوث معك». بدون الاسم تبقى النهاية العامة. لا تحتاجين مشروعاً أو نشراً منفصلاً لكل بنت. يمكن إضافة أي اسم جديد بالرابط دون تعديل الكود. إذا تغيّر عنوان الموقع استخدمي نفس الإضافة مع العنوان الجديد.

## معاينة واتساب

بيانات Open Graph في رأس `index.html` تحدد الشعار والعنوان لكل الروابط، مع أو بدون اسم. بعد الرفع أرسلي الرابط من جديد وانتظري ظهور المعاينة قبل الإرسال. قد تبقى المعاينات القديمة محفوظة مؤقتاً؛ يمكن تجربة إضافة `&v=6` بعد الاسم، مثل `?name=دانا&v=6`. لا يغيّر هذا اسم المدعوة أو اللعبة.
